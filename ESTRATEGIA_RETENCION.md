# 🔄 ESTRATEGIA DE RETENCIÓN - CÓMO MANTENER #1

**Problema**: 60% de apps educativas se abandonan en mes 1  
**Solución**: Retención por diseño (no por suerte)

---

## EL ENEMIGO #1: CHURN (Abandonos)

### Por qué abandonan apps educativas:

```
30% de users:  "Me aburre, no hay progreso"
25% de users:  "No tengo tiempo"
20% de users:  "Pasé a otra app que se ve mejor"
15% de users:  "Aprobar es fácil, ya no necesito"
10% de users:  "Bugs/experiencia mala"
```

**Estrategia**: Atacar cada razón de abandono.

---

## 1. "ME ABURRE" → VARIEDAD CONSTANTE

### Misiones dinámicas (cambiar cada 2-3 días)

```
Lunes:      📝 Palabra del Día (fácil)
Martes:     ❓ Quiz Rápido (5 preguntas)
Miércoles:  🎴 Flashcards (10 cards)
Jueves:     🔤 Sopa de Letras
Viernes:    📚 Tema Nuevo (lectura 20 min)
Sábado:     💯 Quiz Completo (10/10)
Domingo:    🏆 Desafío Especial (bonus)
```

**NO hacer lo mismo cada día** → Aburrimiento.

### Sorpresas aleatorias

```
5% de probabilidad en cada quiz:
"🎁 ¡BONUS! Encontraste +50 XP extra"

"🌟 Streak multiplier activado: ×1.5 por 24h"
```

**Psicología**: Variable rewards (máquina tragaperras educativa)

### Eventos temáticos semanales

```
Semana 1: "⚡ Velocidad Extrema" (quiz rápido)
Semana 2: "💯 Perfeccionista" (3 quizzes 100%)
Semana 3: "🧠 Enciclopedia" (lee todos temas)
Semana 4: "🎯 Consistencia" (7 días racha)
```

**Recicla**: Cada mes reinicia el ciclo de eventos.

## 2. "NO TENGO TIEMPO" → SESIONES CORTAS

### Misiones completables en 5-15 min

```
Daily Word:           1 min  ✓
Quiz Rápido (5 preguntas):  5 min  ✓
Flashcards (10):      5-7 min  ✓
Sopa de Letras:       10 min  ✓
```

**Total mínimo**: 21-23 min/día (aceptable)
**Total máximo**: 45-60 min/día (para enganchados)

### Offline mode

```
Si no hay internet:
- Todos los quizzes funcionan (sync después)
- Flashcards sin internet
- Lectura de temas sin internet

NO perder progreso = NO frustración
```

### Mobile-first (PWA)

```
✅ Funciona en Chrome (computadora)
✅ App en iPhone/Android (PWA)
✅ Zero install friction
✅ Actualiza automático
```

## 6. NOTIFICACIONES (Arma de doble filo)

### CORRECTO: Adictivas sin ser molestas

```
Lunes 08:00  "☀️ Buenos días Lucía. Racha: 7 días 🔥"
Jueves 19:00 "¿Completamos hoy? Falta poco para Nivel 5"
Viernes 20:00 "🏆 Este fin de semana hay evento especial"
Domingo 10:00 "¿Ya hiciste tu racha? (No olvides 🔥)"
```

**Máximo**: 3 notificaciones/semana  
**Horario**: 08:00 - 21:00 (respetar sueño)  
**Personalizable**: "Silenciar notificaciones"

### INCORRECTO (Evitar):

```
❌ "¡Llevas 1 hora sin estudiar!" (pressure)
❌ "Otros usuarios te pasaron" (guilt)
❌ "¿Por qué no estudias como ayer?" (shame)
❌ >1 notificación/día sin contexto
```

**Duolingo es adictivo sin ser tóxico** → Ese es el modelo.

## 7. RACHA: EL CORAZÓN DE LA RETENCIÓN

### Psicología de la racha

```
Día 1-3:  "Me estoy comenzando"
Día 4-7:  "No quiero perder esto" ← Punto crítico
Día 8-14: "Tengo una racha!" ← Orgullo
Día 15+:  "Mi identidad es opositora que estudia"
```

**Mecanismo**: Miedo a perder + orgullo + identidad

### Reset inteligente

```
Si pierde racha:
- Notificación: "¡Perdiste tu racha! Pero puedes recuperarte 💪"
- Opción: "Recuperar racha" (1x por mes, gratis)
- NO castigo permanente

Diseño: No alienar, motivar
```

### Racha visual

```
🔥        (1-2 días)
🔥🔥      (3-6 días)
🔥🔥🔥    (7-14 días)
👑        (15+ días)
```

**Gamificación**: Mostrar progreso visible.

## 9. GAMIFICACIÓN SIN BURNOUT

### PELIGRO: Gamificación excesiva causa fatiga

```
NO hacer:
- "Necesitas 500 XP para desbloquear X" (frustración)
- Puntos por TODO (devalúa puntos)
- Competencia constante (agotamiento)
- Misiones imposibles (abandono)
```

### HACER:

```
✅ Misiones alcanzables (70%+ completan hoy)
✅ Puntos significativos (ver barra llenar es satisfacción)
✅ Descansos sugeridos ("Tómate un descanso 💚")
✅ Flexibilidad (no es obligación, es juego)
```
