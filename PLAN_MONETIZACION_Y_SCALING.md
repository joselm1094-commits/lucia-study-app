## FASE 5: PREMIUM FEATURES (Abr-Sep 2027)

### Mentoría de Humanos

```
MARKETPLACE DE MENTORES

Problema: Usuarios avanzados quieren retroalimentación real

Solución:
├─ Opositores aprobados → Mentores verificados
├─ Ofrecen: "Revisar mi ejercicio" (PDF)
├─ Precio: 5€ por revisión (tú cobras 3€, mentor gana 2€)
├─ Sistema de ratings (5 estrellas)

Ejemplo:
- Lucía aprobó I2 → Se hace mentor
- Otros pagan 5€ para que revise test
- Lucía gana dinero, te lo quitan 40%
- Retention: "Lucía mentoriza a otros" = identidad
```

### Análisis Avanzado

```
"¿VOY A APROBAR?" - PREDICTOR ML

Inputs:
├─ % aciertos actual vs media
├─ Consistencia (racha)
├─ Curva de aprendizaje (mejora/semana)
├─ Comparativa vs aprobados históricos
└─ Días hasta examen

Output:
"Probabilidad de aprobar: 78%"
"Deberías enfocarte en Penal (tu debilidad)"
"Comparado a otros, vas el 65º percentil"

Precio Premium: Incluido en PREMIUM ($19,99)
```

### Certificados

```
"CERTIFICADO DE PROGRESO"

Cuando Lucía alcanza Nivel 9:
├─ Descargable PDF (con su nombre)
├─ "Completé 2,000+ XP en Lucia Study"
├─ "Alcancé Nivel 9 - Supremo"
├─ Compartible: LinkedIn, Instagram
```
