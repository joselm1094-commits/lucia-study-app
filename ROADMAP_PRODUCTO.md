# 📋 ROADMAP PRODUCTO - RUTA HACIA #1

## FASE MVP (Ahora - Octubre 2026)

**Lo que ya tienes:**
- ✅ 5 temas de I2 con memorables (películas/series)
- ✅ Quiz (10 preguntas)
- ✅ Flashcards (SM-2 inteligente)
- ✅ Sopa de Letras
- ✅ Lector de Temas
- ✅ Gamificación (misiones, niveles, racha)
- ✅ PWA (PC + móvil)

**QUÉ FALTA ANTES DE LUCÍA (Crítico):**

### 1. ONBOARDING PERFECTO (Día 1: <5 min)
```
1. ¿Cuál es tu oposición? (dropdown: I2, Policía, GC, etc)
2. ¿Cuándo es tu examen? (date picker)
3. ¿Cuántos min/día tienes? (slider: 30-120 min)
4. Nombre + avatar básico (4 opciones)
5. ¡Listo! → Primer quiz (3 preguntas)
6. Aha moment: "¡Subiste 10 XP!"
```

**Métrica**: <2 min para primer quiz (Duolingo logra esto)

### 2. NOTIFICACIONES ADICTIVAS (Enviadas bien)
```
08:00 "☀️ Buenos días, Lucía. Tu racha está en 7 días 🔥"
13:00 "Falta poco para el siguiente nivel (850/1000 XP)"
20:00 "📅 Reto del día: ¿Completas hoy?" [Sí] [Después]
```

**NO HACER**: >1 notificación/día (Duolingo: 2 máx)
**MÉTRICA**: 40%+ click-through (industria: 25%)

### 3. SISTEMA DE RACHA (Lo tienes, optimizar)
```
Día 1: "🔥 Comienzas fuego"
Día 3: "¡3 días! Racha iniciada"
Día 7: "🔥🔥 En llamas (×1.25 bonus)"
Día 14: "🔥🔥🔥 Inferno (×1.5 bonus)"
Día 30: "👑 Leyenda mensual (×2.0 bonus)"

Resetea si falta 1 día → DOLOR
```

**IMPLEMENTAR**: Pop-up si falta app >12h: "¿Dónde estabas? 👀"

### 4. DASHBOARD ADICTIVO
```
┌──────────────────────────────────┐
│ Nivel 4 🟣 Erudito               │
│ 850 / 1000 XP (85% hacia Lvl 5)  │
│                                  │
```

**PULIR**: Colores vivos, animaciones suaves (no pesadas)

### 5. ELIMINACIÓN DE FRICCIONES

**Objetivo**: Que Lucía llegue a Nivel 9 (Supremo) o Nivel 7 (Genio) en 60 días

**Features paralelos:**

### 1. REPORTE DE PROGRESO PERSONALIZADO
```

- Palabra día: 7/7 ✅
- Racha: 35 días 🔥

```

```
- Derecho Civil: 65% (necesitas work)

```

**Implementar con**: Lógica simple (% de aciertos por tema)

### 3. COMUNIDAD INCIPIENTE (Solo para Lucía + nosotros)
```
(Lo dejas de lado ahora, pero:)
- Grupo privado WhatsApp: José + Lucía + Alejandro
- Comparar XP diarios
- "Lucía, vas 300 XP arriba de Alejandro esta semana"
```

### 4. TRACKING DE SALUD MENTAL
```
Cada misión completada: "¿Cómo te sientes?"
└─ 😊 Bien / 😐 Normal / 😠 Frustrado

Si >3 veces 😠: "Tómate un descanso, necesitas"
```
