═══════════════════════════════════════════════════════════════════════════════
                         CÓMO EXPANDIR A 17 TEMAS
═══════════════════════════════════════════════════════════════════════════════

Es MUY fácil agregar más temas. Simplemente:

1. Abre: lib/content.ts
2. Agrupa un nuevo objeto tema al array "themes"
3. Completa: id, título, descripción, keyPoints, memory, words
4. Guarda y recarga la página

Ejemplo:
────────
{
  id: 6,
  title: "Nombre del Tema",
  description: "Descripción",
  keyPoints: ["Punto 1", "Punto 2"],
  memory: {
    title: "Comparativa",
    description: "Con película/serie",
    example: "Ejemplo concreto"
  },
  words: [
    { word: "Término", definition: "Definición" }
  ]
}

═══════════════════════════════════════════════════════════════════════════════
                              TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: "Cannot find module"
SOLUCIÓN:
  rm -recurse -force node_modules
  npm install
  npm run dev

PROBLEMA: "Port 3000 in use"
SOLUCIÓN:
  set PORT=3001
  npm run dev
  Abre: http://localhost:3001

PROBLEMA: "App no carga en móvil"
SOLUCIÓN:
  • Verifica misma red WiFi
  • Usa IP completa con puerto (192.168.1.100:3000)
  • Usa Chrome en Android, Safari en iOS
